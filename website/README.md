# تطبيق منظومة المقياس

هذا المجلد هو التطبيق التنفيذي الوحيد. شغّله واختبره من داخله.

## التشغيل

```bash
pnpm install
pnpm run dev
```

ثم افتح `http://localhost:3000`.

## الفحوص

```bash
pnpm run lint
pnpm run typecheck
pnpm run test
pnpm run build
```

## متغيرات البيئة

انسخ `.env.example` إلى `.env.local` واملأ القيم المطلوبة. لا ترفع `.env.local` إلى Git.

- القيم العامة: عنوان Supabase، المفتاح القابل للنشر، وعنوان التطبيق.
- القيم الخادمية: مفتاح الخدمة وسر Jotform.
- قيمة حماية المعدل مطلوبة في الإنتاج.

## قاعدة مهمة

وجود migration داخل `supabase/migrations` لا يثبت تطبيقه على قاعدة البيانات الفعلية. طبّق ملفات الترحيل بالترتيب، ثم اختبر كل خطوة بحسابات وصلاحيات حقيقية.
