# مساحة عمل منظومة المقياس

مستودع واحد يضمّ تطبيق الويب وموارد المشروع.

## البنية

```
website/           ← تطبيق Next.js (المنصة الإنتاجية)
project-resources/ ← مستندات تصميم وقرارات وأصول وتقارير تاريخية
```

## التشغيل المحلي

```bash
cd website
pnpm install
pnpm run dev
```

## أوامر الجودة

| الأمر              | الغرض                          |
| ------------------- | ------------------------------ |
| `pnpm run typecheck` | فحص أنواع TypeScript           |
| `pnpm run test`      | تشغيل 100 اختبار آلي          |
| `pnpm run lint`      | فحص ESLint (Next.js + TS)      |
| `pnpm run build`     | بناء الإنتاج                   |

## الحالة المثبتة محليًا

- البناء وفحص الأنواع ناجحان.
- جميع الاختبارات الـ 100 ناجحة.
- فحص ESLint ناجح بلا أخطاء أو تحذيرات.
- ثبتت ملفات الترحيل 026–031 على Supabase الرسمي بفحوص قراءة مباشرة للجداول والدوال، لكن اختبار الأدوار والعزل ببيانات اعتماد حقيقية لم يكتمل بعد.
- نموذجا Jotform القبلي والبعدي مفعّلان وتحققت بنيتهما عبر API، لكن لا يوجد Webhook مسجل لأي منهما.
- `SUPABASE_SERVICE_ROLE_KEY` و`JOTFORM_WEBHOOK_SECRET` موجودان الآن محليًا دون كشف القيم.
- Vercel لم يبدأ، و`NEXT_PUBLIC_APP_URL` ما زال محليًا؛ لذلك لا يوجد HTTPS عام لتسجيل Webhooks أو اختبار QR خارجي.
- سمح صاحب المشروع بإنشاء حسابات وبيانات اختبار مؤقتة للأدوار الأربعة؛ لم تُنشأ بعد.

راجع `website/README.md` للتشغيل ومتطلبات البيئة، و`project-resources/README.md` لخريطة المراجع.
