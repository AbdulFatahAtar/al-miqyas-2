# مساحة عمل منظومة المقياس

مستودع واحد يضمّ تطبيق الويب وموارد المشروع.

## المرجع الموحد

ابدأ بملف [المتطلبات والحالة وخطة الإغلاق الموحدة](project-resources/reports/PROJECT_MASTER_REQUIREMENTS_STATUS_AND_EXECUTION_PLAN_2026-08-12.md). يجمع حزمة التسليم الأصلية والقرارات والتصميم والعقود وملفات التسليم التاريخية، ويحدد نقطة الاستئناف الحالية.

## البنية

```
website/           ← تطبيق Next.js (المنصة الإنتاجية)
project-resources/ ← مستندات تصميم وقرارات وأصول وتقارير تاريخية
```

## التشغيل المحلي

```bash
cd website
pnpm install
pnpm run dev
```

## أوامر الجودة

| الأمر              | الغرض                          |
| ------------------- | ------------------------------ |
| `pnpm run typecheck` | فحص أنواع TypeScript           |
| `pnpm run test`      | تشغيل 106 اختبارات آلية       |
| `pnpm run lint`      | فحص ESLint (Next.js + TS)      |
| `pnpm run build`     | بناء الإنتاج                   |
