# Brand specification

- Product: منظومة المقياس
- Operator: شركة الأمد
- Direction: RTL / Arabic first
- Visual language: institutional, evidence-led, restrained technical interface
- Fonts: IBM Plex Sans Arabic and IBM Plex Mono
- Tenant accent: `#C9A24B`
- Live data accent: `#35C6E6`
- Bundled Al-Amad assets: `public/brand/al-amad-logo.png` and `public/brand/al-amad-mark-transparent.png`
- Application mark: use the transparent asset so it remains valid in Light and Dark modes
- Provenance: the bundled mark matches the mark used by the public Al-Amad site reviewed on 2026-08-02; final production artwork approval still belongs to the project owner
- Tenant logo fallback: an explicit text placeholder only; no invented tenant mark
