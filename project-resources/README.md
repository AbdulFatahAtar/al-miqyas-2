# موارد المشروع — project-resources

مستندات مرجعية وأصول لا تنتمي لشفرة المصدر.

## البنية

```
documentation/
  handover/       ← ملفات التسليم بين الفرق
  specs/          ← وثائق المتطلبات والمواصفات

planning/
  decisions/      ← قرارات المنتج والتصميم
  baseline/       ← ملفات التخطيط ومهام التنفيذ

design/
  references/     ← أدلة التصميم والكتابة
  assets/         ← شعارات وصور بصرية

handoff/          ← ملف التسليم الأصلي (al-miqyas-handoff)
legacy/           ← ملفات أولية تاريخية (v2.jsx إلخ)
ai-instructions/  ← أوامر وسياسات الذكاء الاصطناعي
reports/          ← تقارير وملفات عمل تاريخية من المراحل السابقة
```

## ملاحظة

هذه الملفات **لا تُنشر** مع التطبيق. هي سجل مرجعي لفريق التطوير.

قبل تعديل الواجهة، اقرأ مراجع التصميم والقرارات والمهارات المناسبة داخل `ai-instructions/`.
